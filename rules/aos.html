The Nobulous Set · Game Three

Automaton of Shale (AoS)

Commit everything before you know anything. Precision pays; overkill costs.

You are the Technician running Nobulous’ automaton through its paces. Each Program is a row of elements that must all be funded before a single die is rolled — and Nobulous reveals what you may not use only after you have already committed the components the Program demands.

Components

  • 6 Experimental Technician cards
  • 24 Program cards (double‑sided Stable / Overheated) in three decks of 8: Routine, Specialized, Unstable
  • 8 Advanced Program cards (double‑sided)
  • 6 Limitation cards
  • 5 Element allocation mats
  • From 20 Strong: the 17 unit dice — 4 Purple, 4 Blue, 4 Green, 4 Yellow, 1 Red
  • From 20 Strong: the 3 stat dice — Health, Strategy and Recovery — and the Chip

  2. Build your Program deck — this is your difficulty. Take the stated number of Programs at random from each of the three decks, shuffle the 8 together, and return the rest to the box:

  3. Shuffle the 6 Limitations into a face‑down deck.

Object of the game

Cycle your 8‑card Program deck three times, then face three Advanced Programs. Finish Advanced Programming with at least 1 Health to win. If your Health reaches 0 at any point you lose. Health can be raised by Program Rewards but never above 6.

Cycling the deck

A cycle is one pass through every Program still in the deck: shuffle it, then run each Program once, in the order it comes up. Programs leave the deck permanently when they are set aside or when a Program Reward removes them, so later cycles are shorter. After the third cycle — or as soon as the deck is empty — go to Advanced Programming.

Running a Program

This order matters more than anything else in the game.

  1. Reveal the Program. It shows a row of elements, each with a Target, and one element ringed as the overheat marker.
  2. Reveal the Limitation. It withholds dice from your available pool or imposes a constraint. Withheld dice cannot be used in this Program at all — not even for a required color.
  3. Commit required‑color dice. Every colored dot beside an element requires one available die of that color to be placed on that element now. These dice are locked there.
  4. Finish the allocation. Distribute the rest of your available dice across the elements. An element may be left with no dice at all — it then simply fails.
  5. Execute. Roll each element and resolve it. A hit is 1 success, a Crit is 2.
  6. Recover dice equal to your REC at the end of every Program, before the next one is revealed.
Required colors Red can never satisfy a required‑color dot. A required die counts normally toward its element’s Target — it just has to be that color, and it has to come from the dice the Limitation left you.
If you cannot supply a required color Do not execute the Program. Lose 1 Health. Return any withheld dice, discard the Limitation, and treat the Program as failed for Stable/Overheated progression, then move on. Running your colors dry — or letting a Shortage do it for you — has a real cost.

Specialized and Advanced Programs carry two required‑color dots; Routine and Unstable carry one. The same required colors appear on both faces of a Program card.

Limitations

Reveal exactly 1 Limitation per Program, right after the Program and before any required‑color dice are committed. Each withholds dice from your pool, as printed. Withheld dice return when the Program ends; discard the Limitation then.

Allocation cap

An element may hold at most Target + 1 dice, unless a card raises that cap — the Engineer does, for up to 2 elements per Program.

Rolling and the exhaustion gradient

Each element gets one Strategy roll. Additional rolls up to your STR form a shared pool spent anywhere in the Program — at STR 2 that is one extra roll for the whole Program. An extra roll is a full reroll of that element’s dice: pick the element up, roll all of them again, and the new result replaces the old one, better or worse.

Dice come back unless you are punished Allocating dice is not spending them. When an element resolves, its dice return to your available pool — except for the ones the table below burns.

Anything not listed below costs nothing.

Catastrophic Failure Failing exactly one element in a Program costs no Health. Failing two or more in the same Program is one Catastrophic Failure and costs 1 Health total.

Program Rewards

Every Program in the Routine, Specialized and Unstable decks prints a Program Reward. Claim it when you complete that Program with no failed elements at all — one failure is enough to lose it, even though one failure costs no Health.

The reward is printed on the Program. Two of them — +1 REC and +1 STR — are permanent, and remove that Program from the deck when claimed. Advanced Programs carry no reward.

Stable, Overheated, set aside

  • When a Stable Program fails, flip it to Overheated. The ringed element’s Target increases on that face.
  • If an Overheated Program fails again on a later appearance, set it aside.
  • The endgame triggers after you have cycled the Program deck three times.

Advanced Programming

  • Select 3 Advanced Programs. They are longer — 4 or 5 elements — and each carries 2 required‑color dots resolved by the normal pre‑allocation rule.
  • Recover between Advanced Programs.
  • Tucking: set‑aside Programs may be tucked under the left or right edge of an Advanced Program; the exposed edge Target adds an element. If the marked overheated element is first or last, that edge must be used; if it is internal, you choose.
  • Advanced Program 1 begins Stable.
  • The next Advanced Program begins Overheated if this one ended in Catastrophic Failure, and Stable otherwise. Catastrophic Failure does not stop Advanced Programming unless Health reaches 0.

Complete all three with Health remaining to win AoS.

Carrying AoS forward

Only relevant if you are playing the Nobulous Research Journal (NRJ) campaign.

The 3 Advanced Programs you actually faced are retained, preserving whether each was Stable or Overheated when faced. Three unused Advanced Programs become candidates. AoS contributes 6 cards to the Research Pool.

Stable retained cards are stronger for reducing Targets in the finale but cannot be discarded to avoid a Scenario; Overheated ones are weaker but can.
